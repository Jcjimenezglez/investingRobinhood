# Tapefund Desk MCP

Use the npm package — same shape as [rosetta-mcp](https://www.npmjs.com/package/rosetta-mcp).

```bash
npx -y tapefund-mcp
```

Docs: https://tapefund.com/use/  
Package: `packages/tapefund-mcp`

This folder’s `server.mjs` is a local shim that runs `packages/tapefund-mcp/dist/index.js`.
